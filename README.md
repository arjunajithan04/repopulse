# GHAnalyst_StreamLit
An AI-Driven GitHub Repository Storyteller which perfectly bridges backend API engineering, data analytics, and Generative AI.

## Features
- Repository overview and health insights
- Contributor activity and trends
- Codebase quality metrics
- Streamlit dashboard interface

## Tech Stack
- Python
- Streamlit
- GitHub API
- Pandas

## Run locally
```bash
python -m pip install -r requirements.txt
streamlit run app.py
```
